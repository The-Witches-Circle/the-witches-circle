# The Witches Circle — Studio Website

Official website for **The Witches Circle** indie game studio, live at [thewitchescircle.games](https://thewitchescircle.games).

## About

A single-page static site showcasing the studio and our debut game, **DOPROS** — a dark, Orwell-inspired narrative interrogation game.

## Deployment

Served automatically via **GitHub Pages** from the `master` branch. Pushing to `master` updates the live site within seconds.

Bug reports, typo fixes, and accessibility improvements are welcome — open an [Issue](../../issues) or submit a pull request.
